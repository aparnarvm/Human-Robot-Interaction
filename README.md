## Emotion Recognition using LightGBM and XGBoost
This project analyzes and classifies human emotions from EEG (electroencephalogram) brainwave data using advanced machine learning techniques. 
The dataset used is “EEG Brainwave Dataset: Feeling Emotions” from Kaggle, which contains EEG features corresponding to different emotional states - positive, neutral, and negative.
The workflow covers the complete pipeline - from raw signal preprocessing to model comparison and visualization - aimed at building an interpretable, high-accuracy emotion classifier.
LightGBM happened to perform better than all other comparison models (XGBoost, RandomForest, SVM and Logistic Regression) with an accuracy of 97.6%.
